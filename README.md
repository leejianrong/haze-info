# Haze Info

An interactive website explaining the October 2026 Indonesian haze: where the fires are, which companies hold the burning land, what it does to people's health, how the Indonesian government has responded, and what you can do about it.

Every number on the site links to its source and shows the date it was current. Claims about companies follow the evidence rules in [ADR-0002](docs/adr/0002-attribution-by-evidence-not-accusation.md).

## Develop

```
make dev
make gate     # lint, type-check, unit tests
```
